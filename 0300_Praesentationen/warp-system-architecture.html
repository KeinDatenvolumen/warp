Hochschulprojekt WaRP Java 21 / Spring Boot 4 Microservices

WaRP – Systemarchitektur & Modulübersicht

Weather-aware Route Planning: Frontends (SPA, MPA), API Gateway (BFF), Backend-Services, In-Memory Caches, Middleware, Datenbanken und externe APIs.

Layer 1: Clients & Präsentationsebene
SPA

Frontend (Single-Page Application)

Port: 5173 • React 19.3, TypeScript, Vite

Client-Side

Interaktive Benutzeroberfläche zur dynamischen Routenplanung, Authentifizierung und Wetteranzeige.

Karten-Besonderheit: Die Kartenkacheln (OpenStreetMap / MapTiler Tiles) werden per Leaflet direkt aus dem Browser geladen – bewusst nicht über das Backend gerendert oder durch den BFF geleitet!
Apollo Client (GraphQL) React Router 8 Leaflet Maps CSS Modules
MPA

Multi-Page Application

Port: 8085 • Node.js, Express, EJS

Server-Side Rendered

Klassische serverseitig gerenderte Webanwendung für Auth, Profilverwaltung und Fallback-Flows. Kommuniziert per GraphQL mit dem BFF.

Express.js EJS Templates GraphQL Client
HTTP REST & GraphQL (Port 8080)
Layer 2: API Gateway & Orchestrierung
BFF

bff-service (Backend-for-Frontend)

Single Entrypoint Stateless (No DB)

Port: 8080 • Spring Boot 4.1.1, Java 21, Spring GraphQL

Öffentlicher REST & GraphQL Hub Enforces Internal Service Token

Einziger öffentlicher Zugangspunkt für SPA und MPA. Kapselt die interne Microservice-Landschaft ab, aggregiert Antworten und sichert Downstream-Calls mit einem geteilten internen Service-Token ab.

Downstream 1 Identity (8081)
Downstream 2 Routing (8082)
Downstream 3 Weather (8083)
Downstream 4 Storage (8084)
Interne REST-Calls mit WARP_INTERNAL_SERVICE_TOKEN
Layer 3: Core Domain Services (Spring Boot & Java 21)
ID

identity-service

Port: 8081 • DB: warp_identity

Auth & Identity

Registrierung, Passwort-Hashing (BCrypt), E-Mail-Verifikation, Token-Erzeugung und Sitzungsvalidierung.

⚡ In-Memory Cache: session-lookups
Caffeine (TTL 5m, Max 10k, sync=true)
✉️ Messaging: warp.mail.send
RabbitMQ (Asynchroner Mailversand)
RO

routing-service

Port: 8082 • DB: warp_routing

Geocoding & Routing

Ortssuche, Koordinatenermittlung, Aktivitätsprofile (Fahrrad, Motorrad, Wandern) und Berechnung von Strecken.

⚡ In-Memory Cache: geocoding-results
Caffeine (TTL 24h, Max 5k, sync=true)
🌐 Externe APIs: MapTiler & OpenRouteService
Geocoding + Routing
WE

weather-service

Port: 8083 • DB: warp_weather

Forecast & GenAI

Abruf von räumlich-zeitlichen Wetterdaten entlang einer Route und KI-gestützte Bewertung für Outdoor-Aktivitäten.

🌐 Wetter-API: Open-Meteo API
Stündliche Vorhersagen
✨ Generative AI: Google Gemini API
Wetterbewertung & Empfehlung
ST

storage-service

Port: 8084 • DB: warp_storage

Persistenz & Routen

Verwaltung und Persistierung gespeicherter Benutzerrouten, Favoriten, Routenhistorie und Metadaten.

🗄️ Speicherung: PostgreSQL (warp_storage)
JPA / Hibernate / Flyway
JDBC (DB), AMQP (Queue), SMTP (Mail) & Externe Cloud APIs
